# Incomesify Clips RunPod Worker

This worker renders premium final Shorts at 1080x1920. It uses `h264_nvenc` first and falls back to `libx264` if NVENC is unavailable.

Build this directory as a Docker image and deploy it as a **queue-based RunPod Serverless endpoint**. The WordPress plugin sends premium render jobs to that endpoint and the worker posts the finished MP4 back to WordPress.

Required worker input is generated by the plugin; you do not need to manually craft requests.
